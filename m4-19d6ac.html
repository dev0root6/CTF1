    Files in disguise

    Three files were recovered from the suspect's USB drive. Their names say one thing. Their contents say another.

    A file extension like .txt is just part of the name, and anyone can rename a file. The real type is written in the first few bytes of the file, known as its file signature or magic bytes.

    Below are hex dumps of the first 32 bytes of each file. The left column is the offset, the middle is the bytes in hex, and the right column shows the same bytes as text.

    File 1: holiday_photo.txtxxd

00000010  00 00 04 b0 00 00 03 20  08 06 00 00 00 e4 8c 3a  |....... .......:|
    File 2: voice_note.mp3xxd
