    Mission 05 · Log analysis

    The access log

    On 14 October, confidential project files were downloaded from Kestrel Labs' internal file portal. This is the portal's web server log for that evening.

    Each line is one request: the client IP, the time, the request (method and path), the status code, and the response size in bytes. Status 401 means a login was rejected; 200 means it worked.

    Hints

    Hint 1

    Look for one IP with several 401 responses in a row, followed by a 200.

    Hint 2

    Web addresses can't contain spaces, so they're URL-encoded: %20 is a space and %2E is a dot.

    Hint 3

    Copy only the part after name= into a URL decoder.
